# 🏦 Bank Marketing Campaign Prediction
 
## 📌 Project Overview
 
This project focuses on predicting whether a customer will subscribe to a bank deposit based on demographic, financial, and behavioral characteristics.
 
The main objective is to help financial institutions optimize their marketing campaigns by identifying customers with the highest probability of opening a deposit account.
 
The project applies multiple machine learning classification algorithms and compares their performance using standard classification metrics.
 
---
 
## 🎯 Business Objective
 
Banks invest significant resources into marketing campaigns aimed at attracting new deposit customers.
 
By accurately predicting customer responses, financial institutions can:
 
- Improve campaign efficiency
- Reduce marketing costs
- Increase conversion rates
- Better target potential customers
- Support data-driven decision making
 
---
 
## 📊 Dataset
 
The project uses a banking marketing dataset containing customer information and campaign history.
 
### Features Include
 
- Age
- Job Type
- Marital Status
- Education Level
- Account Balance
- Housing Loan Status
- Personal Loan Status
- Contact Type
- Campaign History
- Previous Marketing Outcome
- Deposit Subscription Status (Target Variable)

## 🤖 Machine Learning Models
 
The following models were trained and evaluated:
 
- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier
- Gradient Boosting Classifier
 
---
 
## 📈 Evaluation Metrics
 
Model performance was assessed using:
 
- Accuracy
- Precision
- Recall
- F1 Score
- ROC AUC
 
---
 
## 📊 Results
 
### Logistic Regression
 
- Accuracy: 81.5%
- Precision: 82.0%
- Recall: 76.9%
- F1 Score: 79.4%
- ROC AUC: 89.6%
 
### Random Forest
 
- Accuracy: 84.7%
- F1 Score: 84.0%
- ROC AUC: 91.4%
 
### Best Performing Models
 
✅ Random Forest
 
✅ Gradient Boosting
 
Both models achieved the strongest overall classification performance and the highest ROC AUC scores.
